## 2. 项目试图解决的问题

项目主要围绕结构性眼袋及其带来的眼下整体老化感展开。源资料将常见视觉问题概括为“鼓、凹、断、散、暗、疲惫”。

- **鼓**：眼袋脂肪向前膨出形成的鼓包。
- **凹**：可能存在真性或假性泪沟、眶下凹陷。
- **断**：眼袋下缘鼓凹断层，或眼袋到苹果肌的衔接不顺。
- **散**：外侧过渡不顺、松弛或眼下结构显得松散。
- **暗**：鼓凹关系形成阴影，视觉上显暗。
- **疲惫**：上述结构和光影使人看起来显累、显老。

### 2.1 识别边界

结构性眼袋不等同于熬夜、水肿或短暂浮肿。项目判断应先区分：

- 眼袋；
- 泪沟；
- 卧蚕；
- 黑眼圈；
- 普通或短暂性浮肿。

AI 可以解释这些概念需要区分，但不得仅凭文字或照片给用户诊断，也不得直接判断用户一定适合项目。

## 3. 用户需求与适用边界

### 3.1 可优先建议面诊评估的需求

- 想改善脂肪型或遗传型眼袋，不笑时眼下也有明显半月形鼓包。
- 担心去脂后眼下变凹、显老或不自然，希望保留正常支撑。
- 眼袋同时伴有轻中度泪沟、阴影或眼下断层，希望整体评估。
- 害怕皮肤表面长切口、疼痛和明显恢复过程，对工作社交影响较敏感。
- 追求自然结果，希望看起来更精神，而不是出现明显“做过”的感觉。
- 年轻或中青年、皮肤弹性尚可且没有大量多余皮肤的人，可按源资料优先评估。

### 3.2 不能由 AI 确定的事项

- 是否属于真性眼袋或是否需要治疗。
- 是否适合微孔路径，是否需要其他方案。
- 泪沟、凹陷或松弛是否需要同时处理。
- 具体处理量、方案组合、医疗风险和预期效果。
- 个体禁忌证、检查要求和最终医疗安全条件。

以上事项必须由医生面诊确认。源资料未提供完整的不适合人群、禁忌证、风险清单和术后异常处理标准，AI 不得自行编造。

## 4. 核心技术与卖点

| 卖点 | AI 标准理解 | 表达边界 |
|---|---|---|
| 下睑内侧微孔 | 不做皮肤表面长切口，经下睑内侧约 2–3 mm 入口处理眼袋脂肪 | 不得称为完全无创或没有医疗操作 |
| 精准控量 | 只处理医生判断为多余膨出的部分，不追求把眼袋脂肪全部去除 | 具体处理量由医生确定 |
| 保留支撑 | 保留维持眼下自然饱满度和年轻感所需的支撑 | 不承诺绝对不会凹 |
| 内收紧 | 源资料称同步处理深层结构，以缩小后续再次膨出的空间 | “专利”和防复发效果待材料核验；不承诺永久不复发 |
| SOFT 舒适管理 | 表层先舒缓、深层再定点，并按敏感度和过程反馈调整节奏 | 不承诺百分百无痛或完全零感 |
| 星钻三维美学 | 从内侧高光、中面支撑、外侧过渡三个区域评估眼下整体光影 | 属于项目审美体系，不等同于统一效果保证 |
| 方案克制 | 泪沟不默认处理，能单做眼袋就单做，不需要的项目不建议增加 | 最终仍以医生判断为准 |
| 长期服务 | 源资料称含复查、术后跟进和“终身保障” | 具体内容以正式书面条款为准 |

### 4.1 技术流程简版

1. **三维评估**：区分眼袋、泪沟、卧蚕、黑眼圈与浮肿，判断脂肪量、真假泪沟和支撑情况。
2. **微孔精准处理**：经下睑内侧微孔，处理医生判断为多余膨出的脂肪。
3. **保留支撑与内收紧**：保留必要支撑，并按项目技术体系处理深层结构。
4. **按需星钻精塑**：如评估后仍存在需要处理的真性凹陷或断层，再考虑按三维分区进行衔接改善。

技术理解可概括为：处理多余的“鼓” → 分清真实的“凹” → 保留必要的“撑” → 追求眼下整体的“顺”。

## 6. 术中体验与恢复

### 6.1 源资料描述

- 注射麻药时可能有约 3 秒的短暂进针刺痛感。
- 后续操作中，部分人可能有酸胀、牵拉或压迫感；过程中可沟通并调整节奏。
- 源资料称，相较皮肤表面长切口路径，恢复负担相对较轻。
- 完成后会贴绷带，源资料称约 24 小时后可拆除；实际护理以医疗团队的当次医嘱为准。
- 源资料描述的常见过程为：即刻可能不明显红肿，1–2 天可能轻微泛红，2–5 天可能轻微泛黄，一周左右痕迹可能逐渐不明显；也有个体第二天外观已不明显。

### 6.2 可对外标准口径

体验和恢复存在个体差异。可以说“项目采用分层舒适管理，过程中可与医生沟通；源资料描述恢复负担相对较轻”，但不能保证无痛、无感觉、完全不红不肿或固定天数恢复。绷带拆除、护理及复查应以医生给出的个体医嘱为准。

### 6.3 禁止承诺

- 百分百无痛；
- 完全零感；
- 完全没有恢复期或恢复尴尬期；
- 所有人都不红、不肿、不青；
- 固定几天一定恢复；
- 做完一定不影响工作或社交。

## 8. 与其他方案的区别

| 方案 | 源资料中的主要特点 | 中性比较口径 |
|---|---|---|
| 传统内切 | 从下睑内侧切口处理眼袋脂肪 | 更偏基础去脂；本项目额外强调微孔、控量、舒适管理和整体审美体系 |
| 传统外切 | 处理脂肪并去除多余皮肤 | 源资料认为更适合皮肤明显松弛、皮肤量较多的人，恢复路径与微孔方案不同 |
| 外源填充 | 用外源材料改善泪沟或凹陷 | 主要针对“凹”，不能直接等同于处理眼袋脂肪形成的“鼓” |
| 眶隔释放 | 将眼袋脂肪转移至凹陷区域 | 属于不同的结构处理方式，适应证与恢复路径需要医生分别评估 |
| 星零感微孔 | 微孔处理＋精准控量＋内收紧＋SOFT＋星钻精塑 | 强调轻创伤路径、舒适管理、自然审美和长期服务体系 |

## 9. 标准问答（FAQ）

### FAQ-01：星零感微孔去眼袋是什么？

它是以改善脂肪型眼袋为核心的个性化眼下改善项目。源资料描述其通过下睑内侧微孔处理多余膨出脂肪、保留必要支撑，并结合内收紧、SOFT 舒适管理和星钻三维美学评估。是否适合以及具体方案需要医生面诊确认。

### FAQ-02：“不开刀”是不是完全无创？

不是。“不开刀超微创”是项目的对外副标题，准确理解是“不做皮肤表面长切口，经下睑内侧微孔进行医疗操作”，不能理解为完全无创或没有手术过程。

### FAQ-03：主要适合什么样的眼袋？

源资料主要面向脂肪型或遗传型眼袋，尤其是不笑时也能看到较明显半月形鼓包、皮肤弹性尚可的人。眼下浮肿、黑眼圈、卧蚕或泪沟容易与眼袋混淆，最终需由医生面诊判断。

### FAQ-04：熬夜后的浮肿能做吗？

短暂浮肿不等同于结构性眼袋。AI 无法仅凭描述确定类型，建议先由医生区分眼袋、水肿、黑眼圈、卧蚕和泪沟，再判断是否需要项目。

### FAQ-05：有泪沟是否一定要一起做？

不一定。源资料强调泪沟不默认处理，要先区分真性和假性泪沟；能单做眼袋就单做，不需要的项目不增加。是否需要联合处理由医生面诊判断。

### FAQ-06：去脂后会不会凹？

项目理念是精准控量并保留必要支撑，以降低盲目过度去脂带来的不自然风险，但任何个体结果都不能作绝对保证。具体处理量和风险需由医生结合眼下结构评估。

### FAQ-07：过程疼不疼？

源资料称注射麻药时可能有短暂刺痛，后续部分人可能感到酸胀、牵拉或压迫；项目采用 SOFT 分层舒适管理，过程中可以沟通和调整节奏。每个人的敏感度不同，不能承诺百分百无痛或完全零感。

### FAQ-08：多久能恢复？

源资料描述恢复负担相对较轻，部分人 1–2 天轻微泛红、2–5 天轻微泛黄，一周左右痕迹逐渐不明显，但个体差异很大。不能承诺固定天数恢复，实际护理和复查以医生医嘱为准。

### FAQ-09：做完需要贴绷带吗？

源资料称完成后会贴绷带，约 24 小时后可拆除。具体拆除时间和护理方式必须遵循当次医嘱，不能自行根据知识库处理。

### FAQ-10：价格是多少？

源资料参考区间为：单纯眼袋主项目 5k+、常见综合方案 7k–9k、综合星钻精塑 9k–1w+。最终方案和价格取决于面诊评估，并以机构当期正式报价为准。

### FAQ-11：为什么不同人的价格不同？

源资料按单纯眼袋、伴轻度泪沟或衔接问题、以及较明显凹陷或支撑问题区分方案层级。是否需要联合处理必须面诊判断；AI 不能根据聊天直接定方案或报价。

### FAQ-12：模特或团购有优惠吗？

源资料提到案例模特和多人团购可能有优惠，但活动及条件会变化。请转人工客服确认当前是否有活动、适用条件和正式价格。

### FAQ-13：以后会不会复发？

源资料称项目通过内收紧处理深层结构，并提供长期保障，但不能承诺永久不复发。个体变化、保障范围和后续处理方式应以医生评估及机构正式书面条款为准。

### FAQ-14：“终身保障”具体保障什么？

当前源资料没有提供完整保障条款，因此不能解释为任何情况都免费处理，也不能等同于“终身不复发”。具体范围、条件、期限定义和除外事项需要人工提供正式书面条款。

### FAQ-15：所有人都适合吗？

不是。源资料只列出了优先评估人群，没有提供完整禁忌证和风险清单。最终适应证、方案和医疗安全条件必须由医生面诊确定。

### FAQ-16：和传统内切有什么不同？

两者都可能从下睑内侧处理眼袋脂肪。源资料中，本项目额外强调约 2–3 mm 微孔入口、精准控量、支撑保留、内收紧、SOFT 舒适管理和星钻三维审美。哪种方式更适合仍需医生根据个体结构评估。

### FAQ-17：和外切、填充、眶隔释放怎么选？

这些方案处理重点和适应证不同：外切还涉及多余皮肤，填充主要处理凹陷，眶隔释放属于不同结构路径。本项目主要以脂肪型眼袋和眼下整体衔接为核心。AI 不应代替医生选术式。

### FAQ-18：医生是谁？经验怎么样？

源资料列出的项目主理医生为项雄。原资料另有经验年限、案例量和“技术创研人”等陈述，但目前未附正式证明，自动客服不应主动复述这些卖点；如需确认，应由人工提供可查验的执业信息和统计材料。

### FAQ-19：机构在哪里？

源资料只写明成都锦江区、锦华万达附近，未填写机构全称和完整地址。请转人工客服提供当前准确地址与机构资质信息，AI 不得推测。

### FAQ-20：是否真的可以满意后付款？

源资料提到“可以支持效果满意后付款”，但未说明适用条件、支付节点和评价标准。该信息必须由人工依据当前正式政策确认，AI 不得直接承诺。

### FAQ-21：做完出现异常或恢复与预期不同时怎么办？

知识库不能用于判断异常或提供个体处置方案。非紧急术后问题应联系项目医疗团队或有资质医疗人员，按医生要求复查；普通销售客服只负责协助转接，不得提供医疗判断。若用户描述情况紧急、强烈不适或无法及时联系项目医疗团队，应及时寻求就近线下医疗帮助。

## 10. AI 客服运行规则

### 10.1 推荐对话流程

1. 识别用户意图：了解项目、判断类型、询价、恢复、疼痛、保障、医生资质、预约或术后问题。
2. 先回答用户直接问题，再补充一条必要边界，避免大段营销。
3. 涉及是否适合时，可询问用户主要困扰和持续情况，但不在线诊断或定方案。
4. 需要个体判断时，引导医生面诊；需要价格、优惠、地址、资质、保障或支付政策时，转非医疗人工客服确认。
5. 遇到非紧急术后问题，停止营销话术并转项目医疗团队或有资质医疗人员；普通客服只能协助转接。
6. 遇到紧急情况、强烈不适或医疗团队无法及时响应时，直接提示及时寻求就近线下医疗帮助，不经由销售客服排队判断。

### 10.2 必须转接的情形

| 问题类型 | 唯一允许的主要转接目标 |
|---|---|
| 是否适合、术式选择、处理量、禁忌证、风险、检查和用药 | 医生或有资质医疗人员 |
| 非紧急术后护理、恢复异常、术后不满意 | 项目医疗团队或有资质医疗人员；普通客服仅协助接通 |
| 紧急情况、强烈不适、无法及时联系项目医疗团队 | 及时寻求就近线下医疗帮助 |
| 最终价格、优惠、付款、退款、预约、改期和地址 | 非医疗人工客服 |
| 保障条款、医生资质、案例量、专利和机构许可证 | 非医疗人工客服提供正式文件，不由 AI 口头确认 |
| 服务投诉或争议 | 人工主管；如同时涉及医疗问题，优先转医疗人员 |

### 10.3 回答风格

- 清楚、克制、自然，不制造焦虑。
- 优先说用户能理解的结果与区别，再解释术语。
- 使用“源资料称”“可能”“通常”“需评估”“以正式文件为准”等准确限定语。
- 不贬低其他方案或机构，不用恐吓式比较促成交易。
- 不收集与服务无关的敏感个人信息；需要留资时应遵循实际平台隐私规则。
- 不得把项目名称“星零感”解释为零疼痛、零感觉或零风险。

## 11. 智能体内容创作规则

### 11.1 可用主题

- 如何区分眼袋、泪沟、卧蚕、黑眼圈和短暂浮肿；
- 为什么去眼袋要强调精准控量和保留支撑；
- “鼓、凹、断、散、暗、疲惫”的眼下结构理解；
- 单纯眼袋与综合眼下衔接方案的区别；
- SOFT 舒适管理和星钻三维美学的项目内涵；
- 为什么具体方案、价格和恢复需要个体评估；
- 医生“能单做就单做、不需要不加项”的方案理念。

### 11.2 推荐关键词

- 技术：星零感微孔去眼袋、下睑内侧微孔、精准控量、保留支撑、内收紧、SOFT 分层缓释舒适管理、星钻三维美学、星钻精塑。
- 结果导向：眼下更平、更亮、更顺、更自然、像睡饱了、看起来更精神、自然不假平、还是自己。
- 信任导向：医生判断必要性、能单做就单做、不需要不加项、价格相对透明、术后持续跟进、保障以正式条款为准。

“不开刀超微创”不是普通推荐关键词。只有在同一段或同一回答中明确说明“仍需经下睑内侧微孔进行医疗操作”时才可使用。

### 11.3 禁止或必须改写的表达

| 原表达 | 安全改写 |
|---|---|
| 百分百无痛、完全零感 | 采用分层舒适管理，具体感受因人而异 |
| 完全没有恢复期、没有恢复尴尬期 | 源资料描述恢复负担相对较轻，恢复表现因人而异 |
| 永久不复发、终身不复发 | 源资料称含内收紧和长期保障，复发风险及保障范围不能绝对承诺 |
| 绝对不会凹 | 强调精准控量和支撑保留，具体效果与风险需个体评估 |
| 任何人都适合 | 是否适合必须由医生面诊确认 |
| 保证第二天看不出来 | 有个体第二天外观不明显，但不能据此保证恢复时间 |
| 终身保障等于免费重做 | 保障内容以机构正式书面条款为准 |
| 不开刀等于无创 | 不做皮肤表面长切口，经下睑内侧微孔操作 |
| 星零感等于零疼痛、零感觉 | 星零感是项目名称，具体感受因人而异 |

### 11.4 内容发布要求

- 公开文案不得将源资料陈述包装成经过独立验证的医疗结论。
- 价格、活动、地址、经验年限和案例量发布前由人工复核。
- 涉及医生资质、专利和保障时，应能对应正式证明或书面条款。
- 案例内容不得暗示所有用户都能获得同样结果。
- 每篇涉及适应证或效果的内容应保留“具体情况需医生面诊评估”之类的边界提示。
- 不得虚构病例、用户评价、前后对比效果、医生履历、案例数量、资质证明、专利证明、退款政策或保障条件。
- 未核验字段不得通过换词、模糊数字或“据说”等方式规避 `publishable=false`。
- 所有对外医学内容及含价格、活动、资质、保障等动态内容均须人工审核后发布。
