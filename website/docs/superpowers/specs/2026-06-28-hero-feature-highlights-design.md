# 首页英雄区特色卖点说明 — 设计文档

日期：2026-06-28
范围：`website/index.html` + `website/assets/home.css`（仅首页，纯静态）

## 背景与目标

用户希望在**英雄区**就让访客（非技术的企业主/运营负责人）第一眼感受到产品"设计得很细、有科技含量"的几个特色卖点：贝叶斯大脑、大五人格、关系运维、知识沉淀等。

关键澄清（用户原话）：贝叶斯和大五**是给运营者观察的数据，方便运营管理、查看运营 Agent 的全部操作与判断**，不是用来自动操控话术的。

## 现状勘察结论（重要）

这些特色**大部分已在站内充分覆盖**，盲目新增会造成重复建设：

- 首页紧邻英雄区下方 `index.html:197-243` 已有四卡板块「同样在跟客户，它做得比人更细」，含：经验沉淀进系统 / 每个客户一张长期记忆卡 / 贝叶斯大脑：不武断会修正 / 因人而异因关系而异（含画像供参考 + 关系分化）。开篇 lead 已写明诚实边界"只观测、只沉淀，绝不替你武断操控"。
- 首页中部 `index.html:427-486`「认知内核：科学方法论」整块讲大五 OCEAN、多轮证据置信（贝叶斯）、诚实置信归零铁律。
- `technology.html:451-494`、`trust.html:280-306`、`engineering.html:306-309`、`solutions.html:398-401` 均有覆盖，且诚实边界一致守住。

因此本次**不是新建重复区块**，而是：英雄区加轻量引导 + 升级现有 197 板块补齐缺口。

## 诚实边界口径（硬约束，全程不可破）

与代码现状、`CLAUDE.md` 红线、站内其他页面保持字面一致：

- **大五人格 / 贝叶斯信号** = 纯观测旁路（`technology.html:471` "只写不读"；`trust.html:305` 契约测试 `bayesian_and_personality_do_not_affect_planner_filters` 守护）。文案只可写：观测、沉淀、越用越懂、诚实标注置信、运营者可查。
- **禁止**写"用大五人格/贝叶斯自动调整话术/回复"——这与代码相反，且与 `index.html:461`、`technology.html:471`、`trust.html:305` 当场矛盾，会砸"可审计/诚实"招牌。
- 真正"驱动行为"的功劳归属：**关系运维**（客户/同行/朋友的语气与节奏分化，真实）、**每联系人口吻微调指令**（真实，最高优先级）、**意图轨迹**（真实改变行为）。
- 正向卖点落点：贝叶斯/大五的价值 = **"AI 对每个客户的判断与依据，运营者/老板全看得到"**（可观测台账、管理复盘），呼应用户强调的管理工具价值。

## 改动一：英雄区特色胶囊（一行 pill）

落点：`index.html` 英雄区 `hero-copy` 内，`<p class="lead">`(88-89) 与 `<div class="hero-cta">`(91) 之间，新增一行特色胶囊。

- 形态：一行可换行的 pill 标签，4 个特色词：贝叶斯大脑 · 大五画像 · 关系运维 · 知识沉淀。每个 pill 是 `<a>`，点击锚点跳到下方升级后的 197 板块（`#why-finer`）。
- 不臃肿原则：胶囊高度小、与 `hero-cta` 按钮拉开间距；放在 lead 与 CTA 之间，作为"先点名特色 → 再引导行动"的过渡。
- 中英双语：每个 pill 内 `data-lang-zh` / `data-lang-en` 成对。
- 不放任何集群/worker 数量（遵守既定红线）。

新增 CSS（`home.css`，hero 段内）：`.hero-feat-pills`（flex wrap，gap，margin 上下）、`.hero-feat-pill`（圆角、半透明白底、细边、hover 提亮、字号 ~13px、行内图标点）。复用既有 token，不引入新色。

## 语言显隐注意（CSS 特异性陷阱）

新增任何带显式 `display`（如 pill 用 `inline-flex`、容器用 `flex`）的双语元素，必须补三条 per-element 语言规则，否则 ZH/EN 同时显示（home.css 晚于 shared.css 加载，显式 display 覆盖 `[data-lang-en]{display:none}`）：

```css
.hero-feat-pill[data-lang-en]{display:none}
html[lang="en"] .hero-feat-pill[data-lang-zh]{display:none}
html[lang="en"] .hero-feat-pill[data-lang-en]{display:inline-flex}
```

（参考既有 `.hero-caps-lead` 同款处理 home.css:34-36。）
